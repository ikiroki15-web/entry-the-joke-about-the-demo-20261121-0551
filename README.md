# The joke about the demo

Entry for make.fun competition `the-joke-about-the-demo-20261121-0551`.

`main.py` writes one one-line joke about working beside an AI coding agent
and something that crashed at the demo, to `entry.txt` in
`$MAKEFUN_OUTPUT_DIR` (default `/output`). UTF-8, one line, under 280
characters, deterministic, no network.
